The result does show why the old distribution-only ceiling was incomplete; it does not attribute a14ms median gap entirely to concat.

GPU sampling also changes random-number consumption relative to CPU sampling: the server prepares fixed nd+1uniforms, whereas CPU speculative rejection can stop drawing earlier. The distribution can remain valid while sampled tokens, routing, acceptance, drafts verified and total pass counts differ for the same prompt/seed/output budget. Match actual step/acceptance telemetry before claiming per-pass savings; no instrumentation should be enabled during the running timing arms. Existing API rolling counters cannot reconstruct every actual row/step. Baseline A1 itself is uninstrumented and comparable to earlier HP values, but B2/A2 fresh-server swapped comparisons are still necessary to bound drift. Retain all arms and record the prediction miss. Neither this source review nor the first-arm gain proves that CDF work caused the full improvement.
