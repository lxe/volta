This baseline does not test the proposed opt-in head-parallel GPU sampler and establishes no candidate gain. Although the environment contains `VOLTA_GPU_SAMPLE=1`, the existing sampler binary explicitly excludes head-parallel mode from GPU sampling, so these runs use the CPU decision path. Future candidate comparisons need the same configuration, workload totals and reversed A/B order; prior standalone peer-copy timings cannot supply that result.
